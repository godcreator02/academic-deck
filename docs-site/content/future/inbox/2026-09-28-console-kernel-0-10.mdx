---
title: 跟进 gwb-kernel 0.10：内核 peer 直接跟到 ^0.10.0
---

来源：总控台的全生态跟进（2026-09-28）。除本仓外，所有 gwb 插件都已把内核 peer 改成 `^0.10.0`；本仓因为有人正在改、且落后好几个大版本，这次没有一起改。

现场：`plugins/academic-deck/package.json` 的 peer 里内核包还是 `^0.7.2`，中间隔着 0.8、0.9、0.10 三个破坏性版本。0.9 那条（`2026-09-27-kernel-request-only.mdx`：删掉 `window.gwb.command` 与 IPC `gwb:command`，页面改用 `@godcreator/gwb-commands/client` 的 `command`）也还没处理。

0.10 本身只改了 `<home>/gwb.log` 的格式：一行一个 JSON `{ ts, level, source, name, msg }`，接口类型、IPC 通道、`gwbKernel` 的成员都没变。代码里若按文本读 `gwb.log` 改成按行 `JSON.parse`；插件的 logger 名不要用 `kernel`、`loader`、`include`、`renderer`。

期望：连同 0.9 那条一起处理，在 0.10 内核的隔离 home 里验过之后把内核 peer 改成 `^0.10.0`、`gwb-commands` 下限跟到 `^0.5.7`，发补丁版。处理完删掉这两条反馈。

证据：内核仓 `docs-site/content/docs/seams/log.mdx`、提交 `7ea49c1`。
