## ① 命令入口：agent → gwb 插件

agent 先读 academic-deck skill，再通过 gwb 查询并调用 deck 命令。插件拥有文件操作、构建进程和浏览器检查的生命周期。

## ② 内容接缝：项目 → 组件包

项目负责 pages、文字、数据和专属素材；组件包提供放映框架、公式、题注与公共样式。汇报锁定自己的组件版本，不因插件升级而自动更换。

## ③ 产物接缝：插件 → 项目文件

创建写入起步项目；构建使用项目安装的 Vite；检查与导出读取 dist。检查报告和截图位于项目 .artifacts，PDF 仅在检查成功后写出。

## ④ 配套版本：组件包 → 插件构建

组件包与插件按同一批次配套发布；插件构建读取组件版本，供新汇报固定依赖。制作流程、组件用法和动画规范全部随插件的 academic-deck skill 发布，由文档站正本生成。
