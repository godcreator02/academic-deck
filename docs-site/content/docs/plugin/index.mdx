## ① 工作台登记命令和 skill

插件通过 gwbCommands 暴露四条写命令，通过 gwbSkills 注册制作说明。没有窗格或独立 CLI。

{/* ref file="../plugins/academic-deck/src/index.ts" lines="12-32" hash="97a0e20abf04" blob="e994b11881b2" */}

## ② 参数进入目录任务

入口校验绝对路径和允许字段，同一目录的操作串行。卸载插件取消在途任务，等待进程、浏览器和服务清理。

{/* ref file="../plugins/academic-deck/src/jobs.ts" hash="4bb34fca73e2" blob="d68a945686b5" */}

## ③ 执行器拥有文件与进程

create 使用 templates/basic；build 调项目安装的 Vite；check 与 export 使用随插件发布的 Playwright 驱动和机器上已安装的 Chrome 或 Edge。项目不必安装浏览器驱动。

## ④ 构建打包与配套版本

插件在构建时读取组件包的版本，打包命令实现与浏览器驱动；skill 与参考文档由文档站 render 到 skills/ 随包发布。两包按同一批次配套发布；组件包只提供汇报运行代码、样式和素材。
