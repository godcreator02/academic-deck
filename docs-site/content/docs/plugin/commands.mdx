## 参数与覆盖保护

目录必须绝对，browser 只接受 chrome 或 msedge；packageSpec 接受固定版本或本地 .tgz 的绝对路径。创建保护由 create.mjs 的独占建目录实现，PDF 写入由 inspect.mjs 使用 wx 实现。

## 谁负责运行与清理

构建超时 120 秒，由 src/build-project.mjs 负责退出码、输出截取和子进程取消。检查、导出超时 180 秒，由 src/inspect.mjs 和 src/static-server.mjs 负责临时服务与浏览器关闭。同一目录的互斥与卸载取消见 src/jobs.mjs。以上路径均相对 plugins/academic-deck。

完整检查明细写在项目 .artifacts/check.json。gwb 回执返回产物位置与页数；返回失败时不能标记交付完成。
