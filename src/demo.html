公式与代码

公式（KaTeX 本地内置，自动渲染）

行内写 $…$：正则项系数 $\lambda>0$ 控制假设空间复杂度。

$$\hat{f}=\arg\min_{f\in\mathcal{H}}\ \frac{1}{n}\sum_{i=1}^{n}\ell\bigl(f(x_i),y_i\bigr)+\lambda\lVert f\rVert_{\mathcal{H}}^{2}$$ (1)

独立写 $$…$$ 或 \[…\]；公式号用 .formula__no 绝对定位在右端。

代码（不受 20pt 下限约束）

# 本地文件，无需联网
import numpy as np

def gap_bound(n, delta, lamb):
    """式(1) 的数值上界"""
    return np.sqrt(np.log(1.0/delta)
                   / (2.0*n)) + lamb
