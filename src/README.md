# 学术风网页演示模板

纯 HTML + CSS + 少量 JS 的翻页演示模板，零构建。浏览器直接打开、打印导出 PDF。
视觉风格来自 `source/2025redyellownew.pptx`（西交大红黄学术答辩模板），**逐页临摹**后反提
设计令牌与组件库——先照抄，后总结。

## 怎么用

```
双击 src/demo.html                          # 看效果（它本身就是模板的视觉规范）
复制 src/ 到你自己的目录                     # 新建一份演示
在 demo.html 里改 .slide 段落，或另写 new.html 引 tokens/deck/components
```

- 翻页：`← →` / `↑ ↓` / `空格` / `PgUp PgDn` / `Home End`；`F` 全屏；点画面右半下一页、左半上一页。
- 导出 PDF：浏览器打印 → 目标「另存为 PDF」、纸张「横向」、边距「无」、勾选「背景图形」。
  `@page` 已把尺寸锁成 1280×720px（= 13.333×7.5in，正好 16:9），一页一 slide，不会裂页。

## 三条已拍板的决策（2026-09-20）

- **D1 主红不区分主次**：`#C00000` 与 `#C92B2F` 并存，各沿用源模板用法。后续加内容就近取色。
- **D2 正文与西文统一固定微软雅黑**（源骨架是思源黑体，为避免别人机器未装时字重跳档而改）；
  代码走常见等宽栈；Arial Black / Tahoma 两个装饰位系统自带，照抄保留。
- **D3 带 KaTeX，含自动渲染，且本地内置**（`assets/katex/`，548KB，不引 CDN，双击即可用）。

## 从 OOXML 搬到 CSS 的四个坑（都有实测依据，别再踩）

1. **`a:lin/@ang` 带 `scaled="1"` 时不是视觉角度**。实测拟合出的规律是
   `CSS角 = atan2(h·cosθ, −w·sinθ)`。三处独立验证：封面校训 176.02° vs 拟合 176.10°、
   章节页 Part 条 6.18° vs 6.18°、封底 THANKS 180° vs 179.73°。
   轴对齐角度（0/90/180/270）用该公式仍得 90/180/270/0°，所以只有非轴角会被坑到——
   直接写 `45deg` 会明显错。详见 `tokens.css` 渐变段注释。
2. **`ln` 的 `algn="ctr"` 表示描边骑在几何边界上、向外溢出半个线宽**。目录页金环是
   `w=57150`(6px)，所以 SVG 路径半径是 `边长/2` 而不是 `(边长−6)/2`；并且 SVG 的
   `viewBox` 必须与元素框 1:1，否则 `preserveAspectRatio` 会把整个环缩小。
3. **底图常常是裁切不是拉伸**。看 `blipFill/srcRect`：章节页底图上下裁掉 20.6%/35.3%，
   目录左栏底图左右裁掉 35.5%/29.0%（后者裁完恰好零变形）。复刻办法是
   「容器 `overflow:hidden` + 整图放大偏移」，`object-fit: cover` 只能居中裁、复刻不出指定裁切框。
   只有封面/封底那张是真空拉伸（`srcRect` 空 + `fillRect`），必须用 `object-fit: fill`。
4. **CSS 渐变默认在预乘 alpha 空间插值，PowerPoint 按直乘**。异色 + 异 alpha 的段会差出
   Δ≈35/765。解法是拆成「不透明颜色层 + `mask-image` alpha 层」（见 `--g-veil-band-*`）。

另外：底部渐变条实测在垂直方向**零变化**（纯一维），且色标曲线不属任何常见插值空间，
故按实测剖面写密色标（`--g-bar`），现状与 PPT 逐点 Δ=0。

## 已知残留 / 第二遍待办

- `assets/bg-toc.png` 11.6MB（源模板市场通病），显示尺寸只有 384×720，可无损降到几百 KB；
  这是体积瘦身的头号目标。
- PowerPoint 与 Chrome 的**降采样核不同**，位图细节处（建筑、树叶）会有 Δ≈15–40 的像素差；
  平滑处 Δ≤4。属于渲染差异，按「肉眼对齐」验收，不做逐像素 diff。
- 字体度量差导致文字上下有 1–2px 偏移（跨字体不可避免）。
- 目录页版式里另有一份校徽被本页那份完全压住，实测墨迹完全一致，故未复刻。
